# 네이버 등록 확인 방법

wow3dp.co.kr 이 네이버에 제대로 등록되었는지 확인하는 방법입니다.

---

## 1. 서치어드바이저 대시보드에서 확인

### 1-1. 소유 확인 상태

1. [네이버 서치어드바이저](https://searchadvisor.naver.com) 로그인
2. **사이트 요약**에서 **wow3dp.co.kr** 선택
3. **상태**가 **「소유 확인 완료」** 또는 **「소유확인됨」** 이면 정상

### 1-2. 사이트맵 제출 상태

1. 왼쪽 메뉴 **요청** → **사이트맵 제출** (또는 **제출 현황**)
2. 제출한 **사이트맵 URL** (`https://wow3dp.co.kr/sitemap.xml`) 이 **등록됨** / **처리 중** / **완료** 로 보이면 제출된 것
3. **수집된 URL 수**가 표시되면 네이버가 사이트맵을 읽고 수집 중인 것

### 1-3. URL 제출 현황 (제출한 경우)

1. **요청** → **URL 제출** 또는 **제출 내역**
2. 제출한 URL 목록과 **처리 상태**(대기, 수집 완료 등) 확인

---

## 2. 네이버 검색 결과에 노출되는지 확인

### 2-1. 사이트 검색 (site: 연산자)

1. [네이버 검색](https://search.naver.com) 이동
2. 검색창에 아래처럼 입력 후 검색:
   ```
   site:wow3dp.co.kr
   ```
3. **wow3dp.co.kr** 로 시작하는 결과가 나오면 네이버에 **수집·색인된 것**
4. 결과가 0건이면 아직 수집 전이거나 색인 대기일 수 있음 (보통 며칠~1~2주 소요)

### 2-2. 사이트명·키워드로 검색

- **「와우3D」**, **「wow3dp 3D프린팅」** 등으로 검색해 보기
- 노출되면 등록·수집이 된 것으로 볼 수 있음 (노출은 검색량·경쟁에 따라 달라짐)

---

## 3. 정리 체크리스트

| 확인 항목 | 확인 방법 |
|-----------|-----------|
| 소유 확인 완료 | 서치어드바이저 → 사이트 요약 → wow3dp.co.kr 상태가 「소유확인됨」 |
| 사이트맵 제출됨 | 요청 → 사이트맵 제출에서 sitemap.xml 등록·처리 상태 확인 |
| 네이버 수집 여부 | 네이버에서 `site:wow3dp.co.kr` 검색 시 결과가 1개 이상 나오는지 |

---

## 4. 참고

- **소유 확인**은 등록 직후 바로 완료로 바뀌고, **사이트맵 제출**도 곧바로 「제출됨」으로 보입니다.
- **검색 결과 노출**(site: 검색에 나오는 것)은 네이버가 크롤링·색인한 뒤에 가능해서 **며칠~1~2주** 걸릴 수 있습니다.
- 서치어드바이저 **요청** 메뉴에 **「수집 요청」**이 있으면, 중요 URL을 넣어 두면 수집이 더 빨라질 수 있습니다.
