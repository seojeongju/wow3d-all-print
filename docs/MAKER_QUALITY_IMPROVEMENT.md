# AI 3D Maker 결과물 퀄리티 개선 제안

펜 형태 등 실물 사진을 업로드했을 때, 현재는 **단순 실루엣 돌출**만 되므로 덩어리처럼 보일 수 있습니다. 아래 순서로 적용하면 품질을 단계적으로 높일 수 있습니다.

---

## 1. 당장 적용 가능 (알고리즘·파라미터)

### 1.1 ImageTracer 옵션 조정 (현재 사용 중)
- **`numberofcolors`**: 2 → **4~8**  
  펜의 몸통/캡/클립 등 색 구분이 나면 실루엣이 더 세분화됩니다.
- **`pathomit`**: 8 → **4 이하**  
  작은 경로를 덜 버려서 디테일(캡, 심 등)이 유지됩니다.
- **`ltres` / `qtres`**: 경계 감도 조정  
  사진처럼 그라데이션이 있으면 값을 낮춰서(예: 0.5~1) 윤곽 추출을 부드럽게 할 수 있습니다.
- **프리셋 분리**  
  - "간단한 로고용" (현재와 유사): 색 2개, pathomit 큼  
  - "사진/실물용(상세)": 색 4~8, pathomit 작게, ltres/qtres 조정  

→ UI에서 **변환 모드: 간단 / 상세** 선택하게 하면 됩니다.

### 1.2 전처리
- **대비(Contrast) 강화**: 캔버스에서 이미지 대비를 올린 뒤 SVG 변환하면 윤곽이 더 선명해집니다.
- **배경 제거**: 객체만 남기고 배경을 제거한 뒤 트레이싱하면 실루엣 품질이 크게 좋아집니다 (아래 API 활용).

### 1.3 SVG 후처리
- **경로 스무딩**: Bezier/스플라인 보간으로 각진 경로를 완만하게.
- **노이즈 제거**: 너무 짧은 선분·작은 폐곡선 제거 후 병합.

## 2. 외부 API / 라이브러리

### 2.1 배경 제거 (객체 실루엣 품질 향상)
- **remove.bg**  
  - API: `https://api.remove.bg/v1.0/removebg`  
  - 사진 → 전경 마스크 → 마스크 외곽선을 SVG로 변환 후 돌출하면 펜 형태가 훨씬 깔끔해짐.
- **Cloudinary**, **Imgix** 등에도 배경 제거/세그멘테이션 기능이 있는 경우 활용 가능.

### 2.2 더 나은 벡터화
- **Potrace** (C 라이브러리, WASM 빌드 가능)  
  - 비트맵 → 경로 품질이 ImageTracer와 다르게 나올 수 있음.  
  - JS/WASM 포트가 있으면 옵션으로 "ImageTracer / Potrace" 선택 제공 가능.
- **벡터화 전용 API**  
  - Vectorizer.ai 등 상용 API로 SVG를 받아서, 그 결과를 현재 파이프라인(돌출 높이 지정 → 3D)에 넣는 방식.

### 2.3 단일 이미지 → 3D (돌출이 아닌 진짜 3D)
- **Meshy**, **Kaedim**, **CSM AI** 등  
  - 이미지 한 장 넣으면 전체 3D 메시를 만들어 줌.  
  - 돌출이 아니라 깊이/곡면이 있는 3D라서 품질 체감이 크지만, 유료·API 호출 제한 있음.
- **Tripo3D**, **Rodin** 등  
  - 무료 티어나 데모가 있는 서비스는 프로토타입에 적합.

## 3. AI 모델 (자체 또는 오픈소스)

### 3.1 세그멘테이션 (객체만 추출)
- **Segment Anything (SAM)**  
  - 오픈소스, 브라우저에서 ONNX/TensorFlow.js 등으로 실행 가능.  
  - “펜” 영역만 마스크 → 마스크 경계를 SVG로 → 돌출하면 실루엣 품질 향상.
- **U²-Net 등**  
  - 배경 제거용 모델로 전경 마스크 생성 후 동일하게 SVG 경로 추출.

### 3.2 깊이 추정 (돌출 높이를 구역별로)
- **MiDaS**, **DPT**  
  - 이미지 → 깊이맵.  
  - 깊이를 Z 높이로 쓰면 “평면 실루엣 + 단일 돌출”이 아니라, 펜 두께·곡면 느낌을 줄 수 있음 (레이어드 컨투어 또는 height map 메시).
- **Zoe Depth** 등  
  - 상대적 깊이만 있어도 “앞뒤” 구분이 되면 2단계 돌출(전경/후경) 등으로 품질 개선 가능.

### 3.3 단일 이미지 3D 생성 (연구/실험)
- **Zero123**, **One-2-3-45** 등  
  - 한 장 입력으로 다각도 3D 또는 노멀맵 생성.  
  - 품질은 높지만 연산·구현 난이도가 크므로 장기 과제로 두는 것이 좋음.

## 4. 적용 우선순위 제안

| 단계 | 내용 | 난이도 | 효과 |
|------|------|--------|------|
| 1 | ImageTracer "상세" 프리셋 추가 (색·pathomit·ltres/qtres) | 낮음 | 실물/펜 디테일 개선 |
| 2 | 배경 제거 API(remove.bg 등) 연동 후 트레이싱 | 중간 | 실루엣 품질 큰 향상 |
| 3 | 전처리(대비)·SVG 스무딩 | 낮음 | 경계선 부드러움 |
| 4 | Potrace 또는 다른 트레이서 옵션 추가 | 중간 | 스타일/품질 선택지 확대 |
| 5 | 깊이 추정(MiDaS 등)으로 구역별 돌출 | 높음 | 2.5D 느낌, 펜 두께 표현 |
| 6 | 단일 이미지 3D API(Meshy 등) 연동 | 중간 | 완전 3D 메시 출력 |

먼저 **1번(상세 프리셋) + 2번(배경 제거)**까지 적용하면, 펜 형태 이미지 결과물 퀄리티를 가장 빠르게 개선할 수 있습니다.

---

## 5. 배경 제거(remove.bg) 설정 방법

- [remove.bg](https://www.remove.bg/api)에서 API 키 발급 (무료 크레딧 제공).
- 프로젝트 루트 또는 서버 환경에 다음 변수 설정:
  - `REMOVE_BG_API_KEY=your_api_key`
- Next.js: `.env.local` 또는 Cloudflare Pages/Workers 환경 변수에 추가.
- 설정 후 AI 3D Maker 오른쪽 패널에서 **「배경 제거 후 변환」**을 켜면 업로드 시 배경 제거 후 SVG 변환이 적용됩니다.
- **일일 한도**: 회원 5회 · 비회원 2회 (Meshy 사진→3D와 동일). JPG/PNG 최대 8MB.
- D1: `npx wrangler d1 execute wow3d-production --remote --file=./migrations/schema_maker_remove_bg.sql`
