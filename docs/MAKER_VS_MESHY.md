# Maker vs 사진→AI 3D (역할 구분)

WOW3D에는 **두 가지 만들기 경로**가 있습니다. 목적에 맞게 안내하세요.

| | **AI 3D Maker** (`/#ai-3d-maker`, `/maker`) | **사진→AI 3D 견적** (`/quote?entry=photo`) |
|--|---------------------------------------------|-------------------------------------------|
| **방식** | 2D 실루엣 → **돌출(2.5D)** | Meshy Image-to-3D → **입체 메시** |
| **적합한 입력** | 스케치, SVG, 단순 로고 PNG | 제품·피규어 **실사 사진** |
| **결과** | 배지·키캡·간판형 | 깊이·곡면이 있는 3D |
| **다음 단계** | STL 저장 또는 **견적 의뢰하기** | 자동견적 → 장바구니 |

## 구현된 고도화 (Phase A)

- Maker 상단 역할 배너 + Meshy 견적 링크
- 「견적 의뢰하기」→ STL 생성 → `useFileStore` → `/quote?entry=file`
- 돌출 높이·베이스 두께 **mm 직접 입력**
- 홈 「모델 파일이 없으신가요?」섹션 이중 카드
- 변환 모드 기본값: **간단(로고)**

## 구현된 고도화 (Phase B)

- **템플릿**: 원형 배지 Ø40mm, 사각 배지 40mm, 키캡 1U 18mm
- **멀티 레이어**: 1층 베이스 / 2층 로고 돌출 / 3층 테두리 림
- **bevel(모따기)** mm — 미리보기와 STL 동일 (`lib/maker-geometry.ts`)
- 판 크기·라운드 mm를 실제 출력 치수에 가깝게 매핑 (`EXPORT_SCALE`)

## 구현된 고도화 (Phase C)

- **키캡 MX 스템**: Cherry MX 간이 십자(+) · FDM 슬롯 1.35mm · 키캡 1U 템플릿 기본 ON
- **배지 뒷면**: 마그넷 컵(Ø10) / 옷핀 채널 — 원형 배지·사각 배지 템플릿 기본값
- **remove.bg**: 일일 한도(회원 5 · 비회원 2), 8MB 제한, 502 1회 재시도, 남은 횟수 UI

## 이후 (참고)

- 레이어별 색(멀티머티리얼)은 FDM 멀티헤드/도색 공정과 맞춰 별도 검토
- MX 스템은 간이 호환입니다. 스위치 공차는 출력 방식에 따라 다듬어야 합니다.
