# Maker vs 사진→AI 3D (역할 구분)

WOW3D에는 **두 가지 만들기 경로**가 있습니다. 목적에 맞게 안내하세요.

| | **AI 3D Maker** (`/#ai-3d-maker`, `/maker`) | **사진→AI 3D 견적** (`/quote?entry=photo`) |
|--|---------------------------------------------|-------------------------------------------|
| **방식** | 2D 실루엣 → **돌출(2.5D)** | Meshy Image-to-3D → **입체 메시** |
| **적합한 입력** | 스케치, SVG, 단순 로고 PNG | 제품·피규어 **실사 사진** |
| **결과** | 배지·키캡·간판형 | 깊이·곡면이 있는 3D |
| **다음 단계** | STL 저장 또는 **견적 의뢰하기** | 자동견적 → 장바구니 |

## 구현된 고도화 (Phase A)

- Maker 상단 역할 배너 + Meshy 견적 링크
- 「견적 의뢰하기」→ STL 생성 → `useFileStore` → `/quote?entry=file`
- 돌출 높이·베이스 두께 **mm 직접 입력**
- 홈 「모델 파일이 없으신가요?」섹션 이중 카드
- 변환 모드 기본값: **간단(로고)**

## 이후 단계 (Phase B+)

- 멀티 레이어 높이, bevel
- remove.bg 안정화·한도 안내
- Maker 템플릿(배지/키캡)
