# Tripo3D 연동 기능 제안

Tripo3D API 설정이 완료되었으므로, wow3d 프로젝트에 넣기 좋은 기능과 우선순위를 정리했습니다.

---

## 현재 AI 3D Maker 흐름 (요약)

- **스케치(2D)**: 마우스로 그리기 → 경로 돌출 → 3D 미리보기 → STL 저장
- **이미지**: 업로드 → (선택) 배경 제거 → SVG 변환 → 돌출 높이 지정 → 3D에 추가 → STL 저장  
→ 모두 **실루엣 돌출** 방식이라 평면적인 느낌입니다.

Tripo3D를 쓰면 **한 장의 이미지나 문장만으로 입체 3D 메시**를 받을 수 있어, 3D 프린팅·견적 플로우와 잘 맞습니다.

---

## 제안 기능 (우선순위)

### 1. 이미지 → AI 3D 생성 (Image-to-3D) — **최우선 추천**

| 항목 | 내용 |
|------|------|
| **내용** | 사용자가 이미지를 올렸을 때, 기존 "SVG 돌출" 대신 **Tripo3D 이미지→3D**로 진짜 3D 메시 생성 |
| **사용자 흐름** | 이미지 업로드 → "생성 방식"에서 **돌출(SVG)** / **AI 3D 생성(Tripo3D)** 선택 → AI 3D 선택 시 API 호출 → 진행 표시 → 완료 시 3D 뷰어에 표시 + 다운로드(GLB/STL) |
| **장점** | 지금 있는 이미지 업로드 UI를 그대로 쓰고, 옵션만 추가하면 됨. 사진 한 장으로 입체 모델을 얻어 3D 프린팅·견적으로 바로 연결 가능 |
| **난이도** | 중간 (비동기 task 제출 → 폴링 → GLB 수신 → 뷰어/다운로드) |

---

### 2. 텍스트 → 3D 생성 (Text-to-3D)

| 항목 | 내용 |
|------|------|
| **내용** | "나무 의자", "로봇 피규어"처럼 **설명만 입력**해 Tripo3D로 3D 모델 생성 |
| **사용자 흐름** | Maker에 **텍스트 입력창** 추가 → 입력 후 [3D 생성] → 동일하게 진행 표시 → 완료 시 뷰어 + 다운로드 |
| **장점** | 그리기/이미지 없이도 아이디어만으로 3D 모델 생성 → 견적·주문으로 이어지기 좋음 |
| **난이도** | 중간 (1번과 같은 비동기·폴링·뷰어 연동, API만 text_to_model로 변경) |

---

### 3. AI 3D 결과 전용 뷰어·다운로드

| 항목 | 내용 |
|------|------|
| **내용** | Tripo3D로 만든 모델은 **GLB**로 오므로, 기존 스케치/SVG 돌출과 별도로 "AI 3D 결과" 목록 관리 |
| **구현** | 스토어에 `tripoModels: { id, name, glbUrl, taskId }[]` 추가 → Preview3D에서 GLB 로드해 표시. 다운로드는 GLB 그대로 또는 클라이언트에서 STL로 변환 후 저장 |
| **장점** | 스케치/이미지 돌출과 AI 3D를 한 화면에서 구분해 관리 가능 |

---

### 4. (선택) 멀티뷰 → 3D

| 항목 | 내용 |
|------|------|
| **내용** | 같은 물체의 **앞/옆/위** 등 여러 각도 사진을 올리면 Tripo3D Multi-view API로 더 정교한 3D 생성 |
| **장점** | 품질 향상. 대신 UI(여러 파일 업로드·순서 지정)와 크레딧 소모가 커서 1·2번 안정화 후 검토하는 것이 좋음 |

---

## 구현 순서 제안

1. **백엔드**
   - `POST /api/maker/tripo3d`  
     - body: `{ type: 'image_to_model' | 'text_to_model', image?: File(base64/url), prompt?: string }`  
     - Tripo3D에 task 제출 후 `task_id` 반환
   - `GET /api/maker/tripo3d?task_id=xxx`  
     - task 상태 조회, 완료 시 `model_url`(GLB) 등 반환

2. **프론트 (이미지 → AI 3D)**
   - Maker 오른쪽 패널 또는 이미지 업로드 영역에 **"생성 방식: 돌출(SVG) | AI 3D 생성"** 선택 추가
   - AI 3D 선택 시 이미지 업로드 → `/api/maker/tripo3d` 호출 → `task_id`로 폴링(또는 재시도) → 완료 시 GLB URL 수신
   - 스토어에 `tripoModels` 추가 후 Preview3D에서 GLB 표시
   - 다운로드: GLB 링크 또는 three.js로 메시 추출 후 STL export

3. **프론트 (텍스트 → 3D)**  
   - 텍스트 입력 UI 추가 → `type: 'text_to_model'`, `prompt` 전달 → 동일 폴링·뷰어·다운로드

4. **환경 변수**  
   - 이미 설정된 `TRIPO3D_API_KEY`를 API 라우트에서 `process.env.TRIPO3D_API_KEY`로 사용

---

## 참고 사항

- **크레딧**: Tripo3D는 요청당 크레딧 소모. 무료 한도 내에서 테스트 후, 필요 시 사용량 안내 문구 추가 권장.
- **폴링 간격**: 2~5초 간격으로 task 조회. 완료 또는 실패 시 중단.
- **GLB ↔ STL**: Tripo3D는 GLB 제공. 슬라이서가 GLB를 지원하면 그대로 다운로드해도 되고, STL이 필요하면 클라이언트에서 GLB 로드 후 STLExporter로 변환 가능.

원하시면 **1번(이미지 → AI 3D)**부터 구체적인 API 스펙과 컴포넌트 수정 예시로 단계별 구현안을 이어서 적어 드리겠습니다.
