# 네이버 사이트맵 제출 시 "접근 실패" / 네트워크 오류 대응

네이버 검색 로봇이 wow3dp.co.kr 에 접속하지 못해 **"HTTP 응답을 받지 못했습니다. (네트워크 오류)"** 가 날 때 점검할 항목입니다.

---

## 1. Cloudflare 보안 설정 확인 (우선)

네이버 봇이 **챌린지(캡차)** 에 걸리거나 차단되면 접근 실패가 날 수 있습니다.

1. [Cloudflare 대시보드](https://dash.cloudflare.com) → **wow3dp.co.kr** Zone 선택  
2. **보안** (Security) → **설정** (Settings)  
   - **보안 수준** (Security Level): **낮음** 또는 **보통** 으로 두기 (높음/Under Attack 이면 봇이 차단될 수 있음)  
   - **봇 투쟁 모드** (Bot Fight Mode): **꺼짐** 으로 두기 (켜져 있으면 봇 트래픽을 의심해 차단할 수 있음)  
3. **방화벽** (Firewall) → **방화벽 규칙** / **WAF**  
   - 네이버·검색엔진 봇을 막는 규칙이 있으면 **비활성화** 하거나 **예외** 추가  
4. 저장 후 **몇 분 뒤** 네이버에서 사이트맵 제출 다시 시도  

---

## 2. 나중에 다시 제출

일시적인 네트워크/라우팅 문제일 수 있으므로:

- **몇 시간 뒤** 또는 **다음 날** 서치어드바이저 **요청** → **사이트맵 제출** 에서  
  `https://wow3dp.co.kr/sitemap.xml` 다시 제출  

---

## 3. 사이트맵 URL만 제출

제출 시 **사이트 주소**가 아니라 **사이트맵 URL**만 넣는지 확인:

- 제출할 URL: **`https://wow3dp.co.kr/sitemap.xml`**  
- (일부 화면에서는 사이트맵 주소 입력란에 위 주소를 정확히 입력)

---

## 4. 외부에서 사이트 접속 확인

다른 네트워크에서 사이트가 열리는지 확인:

- [Down For Everyone Or Just Me](https://downforeveryoneorjustme.com/wow3dp.co.kr) 에서 wow3dp.co.kr 입력  
- 또는 휴대폰 데이터로 https://wow3dp.co.kr 접속  

둘 다 정상이면, 문제는 **네이버 봇 ↔ Cloudflare** 구간일 가능성이 큽니다. → 1번(보안 완화) 후 재시도.

---

## 요약

| 원인 추정           | 조치 |
|---------------------|------|
| Cloudflare 봇 차단  | 보안 수준 낮춤, 봇 투쟁 모드 끄기, 봇 차단 규칙 확인 |
| 일시적 네트워크 오류 | 몇 시간 뒤 사이트맵 제출 재시도 |
| 제출 URL 오류       | `https://wow3dp.co.kr/sitemap.xml` 만 제출했는지 확인 |
