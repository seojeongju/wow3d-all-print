# 검색어(키워드) 노출 최적화

목표 검색어: **3D프린팅출력**, **3D프린팅자동견적**, **3D프린터출력**, **3D프린팅출력서비스**

## 적용된 방법

### 1. 메타데이터 (Title / Description / Keywords)

- **`app/layout.tsx`**
  - **title**: "3D 프린팅 출력·자동 견적 | WOW3D - 3D 프린터 출력 서비스"  
    → 4개 키워드를 자연스럽게 포함
  - **description**: 문장 안에  
    "3D 프린팅 출력", "3D 프린팅 자동 견적", "3D 프린터 출력 서비스" 포함
  - **keywords** 배열:  
    "3D 프린팅 출력", "3D 프린팅 자동 견적", "3D 프린터 출력", "3D 프린팅 출력 서비스" 추가
  - **Open Graph / Twitter**: 동일 키워드가 들어가도록 title·description 통일

### 2. 페이지별 메타 (페이지 타이틀·설명)

- **메인**  
  - 전역 메타 사용 → 위 4개 키워드 포함
- **견적 페이지** (`/quote`)
  - **`app/quote/layout.tsx`**  
    - title: "3D 프린팅 자동 견적 | 파일 업로드 10초 견적"  
    - description: "3D 프린팅 자동 견적", "3D 프린팅 출력", "3D 프린터 출력 서비스" 포함  
  → "3D 프린팅 자동 견적" 검색에 유리

### 3. 본문 텍스트 (헤딩·문단)

- **`components/home/Hero.tsx`**
  - 첫 문단에  
    "3D 프린팅 출력 서비스", "3D 프린팅 자동 견적", "3D 프린터 출력"  
    자연스럽게 포함 (키워드 스터핑 없이 한 번씩 사용)

### 4. 구조화 데이터 (JSON-LD)

- **`app/layout.tsx`**  
  - **LocalBusiness** 스키마에  
    - `name`, `description`, `url`, `image`  
    - `serviceType`:  
      "3D 프린팅 출력", "3D 프린팅 자동 견적", "3D 프린터 출력", "3D 프린팅 출력 서비스"  
  → 검색엔진이 서비스 종류를 이해하고, 노출·리치 결과에 활용할 수 있음

### 5. 기존 SEO 유지

- **robots.txt** (`app/robots.ts`): 크롤링 허용·sitemap 안내
- **sitemap.xml** (`app/sitemap.ts`): 메인, 견적, 소재, 문의 등 공개 URL 포함
- **canonical**: 루트·견적 페이지 등에 설정
- **네이버/구글** 소유 확인 및 사이트맵 제출은 `docs/SEO_SEARCH_REGISTRATION.md`,  
  `docs/NAVER_SEARCH_REGISTRATION.md`, `docs/GOOGLE_SEARCH_REGISTRATION.md` 참고
