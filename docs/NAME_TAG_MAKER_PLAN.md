# 이름표 만들기 고도화 개발 계획서

- 작성일: 2026-10-21 (KST)
- 대상: `/maker` 이름표 만들기 (`components/maker/NameTagStudio.tsx`)
- 목표: 일반 사용자에게 공개하고, 개인·단체 주문을 받을 수 있는 수준으로 올린다.

---

## 1. 결론 요약

지금 이름표 만들기는 **글자를 판 위에 올려 보여 주는 데모**입니다. 공개하려면 세 가지가 먼저 해결돼야 합니다.

1. **출력되는 형상인가** — 글자와 판이 한 덩어리로 합쳐지지 않은 채 STL로 나가고, 출력 가능 여부(획 두께·글자 높이)를 검사하지 않습니다.
2. **원하는 디자인을 만들 수 있는가** — 판 모양, 줄 구성, 정렬, 테두리, 음각/양각, 아이콘을 사용자가 정할 수 없습니다.
3. **바로 주문까지 이어지는가** — 견적으로 STL 파일만 넘어가서 색·소재·수량·디자인 정보가 사라지고, 여러 이름을 한 번에 주문할 수 없습니다.

따라서 순서는 **형상 엔진 → 편집기 → 주문 연계 → 공개 준비 → 확장(이미지·AI)** 입니다. 단계마다 완료 기준을 두고, 기준을 넘지 못하면 다음 단계로 가지 않습니다.

## 2. 현재 상태 진단

| 영역 | 현재 | 공개 기준에서의 문제 |
|------|------|------|
| 형상 | 판·글자를 각각 돌출해 겹쳐 둔 메시 묶음 | STL에 겹친 셸이 남아 슬라이서·견적 부피 계산이 어긋날 수 있음. 음각 불가 |
| 글자 구멍 | 윤곽 bbox 중심 기준으로 구멍 판정 (`contoursWithHoles`) | 복잡한 한글·겹친 획에서 구멍이 메워지거나 빠질 수 있음 |
| 판 | 라운드 사각 1종, 크기 3단계(42×18, 60×24, 80×32) | 원·타원·캡슐·글자 외곽형 없음. 직접 치수 입력 없음 |
| 구멍 | 왼쪽 고정 | 위쪽·양쪽·없음 선택 불가 |
| 텍스트 | 2줄(이름·텍스트), 폰트 4종, 글자 크기 % | 정렬·자간·줄별 크기·자동 맞춤 없음. 판 밖으로 넘쳐도 경고 없음 |
| 출력 검사 | 없음 | 작게 + 두 줄이면 획이 노즐보다 얇아질 수 있는데 사용자가 모름 |
| 색 | 미리보기 색만 있음 | 판/글자 2색 주문, 견적 색상(화이트·블랙·투명·기타)과 연결 안 됨 |
| 견적 연계 | STL 1개를 `/quote?entry=file&handoff=1`로 전달 | 색·수량·디자인 정보 유실, 단체 주문 불가, 주문 후 재생성 불가 |
| 저장 | 없음 | 새로고침하면 작업이 사라짐. 공유·재주문 불가 |
| 미리보기 | 3D만 있음 | 빈 화면에 예전 Maker 안내 문구(배지·키캡)가 남아 있음. 글자 확인은 정면 2D가 더 빠름 |
| 성능 | 고운돋움 약 7MB를 그대로 받음 | 모바일 첫 진입이 느림 |
| 남은 코드 | 아이·강아지·고양이 기준 추천 API(`/api/maker/name-tag-suggest`), 아이콘 묶음 | 화면에서 쓰지 않는 코드가 남아 있음 |
| 검증 | 수동 브라우저 확인만 | 형상·폰트 회귀를 잡을 자동 테스트 없음 |

## 4. 기능 고도화 항목

### A. 형상 엔진 (공개 필수)

- **불리언 합체**: 판 + 글자 + 테두리를 하나의 닫힌 메시로 합칩니다. `manifold-3d`(WASM, Apache-2.0)를 쓰고, 미리보기와 STL이 같은 결과를 씁니다.
- **양각 / 음각**: 글자를 올리거나(양각) 판에서 파냅니다(음각). 음각은 깊이 옵션을 둡니다.
- **글자 구멍 판정 개선**: bbox 중심 대신 윤곽 방향(시계/반시계)과 포함 관계로 판정하고, 최종적으로 불리언이 정리하게 합니다.
- **판 모양 확장**: 사각, 라운드 사각, 캡슐, 원, 타원, 뼈다귀, **글자 외곽형**(글자 윤곽을 일정 거리 키운 판).
- **테두리(림)**: 판 가장자리를 올리는 옵션.
- **구멍**: 위치(왼쪽·위·양쪽·없음), 지름, 구멍 둘레 보강 링.
- **연산 분리**: 형상 계산은 Web Worker에서 하고, 입력 중에는 이전 결과를 보여 줘 화면이 멈추지 않게 합니다.

**완료 기준**
- 모든 프리셋 × 폰트 4종 × 대표 문구 조합에서 내보낸 STL이 단일 매니폴드(열린 모서리 0, 자체 교차 0)입니다.
- 같은 디자인의 미리보기 부피와 STL 부피 차이가 1% 이내입니다.

### B. 출력 가능성 검사 (공개 필수)

- **검사 항목**: 최소 획 두께, 최소 글자 높이, 판 두께, 구멍과 가장자리 사이 여유, 음각 깊이 대비 판 두께.
- **기준값**: 공정별(FDM·레진)로 따로 두고, 실제 출력 테스트로 확정합니다. 확정 전 값은 코드에 "초안"으로 표시합니다.
- **화면 표시**: 문제 위치를 미리보기에서 빨간색으로 표시하고, 이유를 한 줄로 알려 줍니다.
- **자동 보정 제안**: "글자를 키우기", "판을 한 단계 크게", "굵은 폰트로 바꾸기" 버튼을 제공합니다.
- **차단 규칙**: 출력이 불가능한 디자인은 견적 버튼을 막고 이유를 보여 줍니다. 경고 수준이면 진행할 수 있습니다.

**완료 기준**
- 기준 미달 디자인 10종을 일부러 만들었을 때 모두 경고 또는 차단됩니다.
- 실제 출력한 샘플(공정별)에서 경고 없이 통과한 디자인의 글자가 모두 읽힙니다.

### C. 텍스트 편집기

- 줄 수 1~3줄, 줄마다 폰트·크기·굵기(가능한 폰트만) 지정
- 정렬(왼쪽·가운데·오른쪽), 자간, 줄 간격
- **자동 맞춤**: 판 안에 들어가도록 글자를 자동으로 줄이고, 줄일 수 없으면 판 확대를 제안
- 폰트에 없는 글자 경고(현재 있음)를 줄 단위로 표시
- 폰트 확장: 손글씨체·명조체 등 OFL 폰트를 추가하되, 선택할 때만 내려받기

### D. 아이콘·이미지

- 아이콘 라이브러리를 다시 붙입니다(별·하트·발바닥·뼈·물고기·꽃·달 등). 위치는 글자 왼쪽·오른쪽·위로 정합니다.
- 이미지 업로드: 기존 배경 제거(`/api/maker/remove-bg`)와 윤곽 추출을 재사용해 로고·실루엣을 올립니다. 출력 검사(B)를 그대로 통과해야 합니다.

### E. 색상·소재

- 판 색, 글자 색을 각각 선택합니다. 선택지는 자동견적 색상 규칙(`lib/print-color.ts`)과 같습니다.
- 2색이면 판과 글자를 분리한 **3MF**(색 정보 포함)로 내보내고, 1색이면 STL로 내보냅니다.
- 음각 + 색 채움은 후가공 옵션으로 견적에 표시합니다.

### F. 단체 주문

- 이름 목록 붙여넣기 또는 CSV 업로드(이름, 둘째 줄 문구)
- 같은 디자인으로 목록 전체를 미리보기 표로 생성하고, 줄마다 출력 검사 결과를 보여 줍니다.
- 견적은 1건으로 묶어 수량과 개별 파일을 함께 넘깁니다(ZIP 또는 다중 파일).

### G. 견적·주문 연계

- **이름표 전용 가격 미리보기**: 화면에서 부피를 계산해 기존 견적 엔진 기준 예상 가격을 보여 줍니다.
- **디자인 정보 전달**: 견적으로 넘길 때 파일과 함께 디자인 JSON(문구·폰트·판·색·수량)을 넘기고, 소재·색을 미리 선택해 둡니다.
- **주문에 디자인 저장**: 관리자 주문 화면에서 디자인 JSON으로 같은 형상을 다시 만들고, 문구를 확인할 수 있게 합니다. 오탈자 확인용 PNG 미리보기를 주문에 첨부합니다.

### H. 저장·공유

- 작업 중 자동 저장(브라우저 저장소)
- 공유 링크: 디자인 JSON을 링크로 만들어 다시 열기
- 로그인 사용자는 "내 디자인"에 저장하고 재주문

### I. 화면·사용성

- **2D 정면 편집 미리보기**를 기본으로 하고, 3D는 확인용 탭으로 둡니다. 2D에서 글자·아이콘 위치를 바로 확인합니다.
- 프리셋 갤러리(3절의 다섯 용도)로 시작하고, 빈 화면이 나오지 않게 합니다.
- 실행 취소/다시 실행
- 모바일: 미리보기 위, 편집 패널 아래 시트 구조. 엄지로 조작할 수 있는 크기
- 빈 상태·오류 문구를 이름표 기준으로 바꿉니다(현재 배지·키캡 문구가 남아 있음).

### J. 성능

- 폰트는 선택한 것만 내려받고, 처음에는 가벼운 폰트로 시작합니다.
- 고운돋움은 자주 쓰는 한글 2,350자 중심으로 다시 줄이거나, 입력한 글자만 서버에서 잘라 주는 방식을 검토합니다.
- 형상 계산은 Worker에서 하고, 입력 디바운스를 유지합니다.

### K. AI (확장, 공개 이후)

- 문구에 어울리는 프리셋·폰트·아이콘을 **허용 목록 안에서만** 추천합니다. AI가 형상이나 치수를 직접 만들지 않습니다.
- 현재 아이·강아지·고양이 기준 추천 API는 프리셋 기준으로 다시 만들거나 삭제합니다.

### L. 품질 관리

- **형상 테스트**: 프리셋 × 폰트 × 문구 조합으로 매니폴드 여부, 부피, 경계 상자 치수를 자동 검사
- **폰트 테스트**: 각 폰트의 한글 완성형·숫자·하이픈·영문 지원 여부 검사
- **화면 테스트**: 문구 입력 → 견적 이동까지 브라우저 자동 테스트
- **이용 지표**: 진입, 첫 문구 입력, 견적 이동, 주문 완료, 이탈 단계 이벤트

## 5. 단계별 로드맵

규모는 S(1~3일) / M(1주 내외) / L(2주 내외) 기준의 상대값입니다.

| 단계 | 내용 | 규모 | 완료 기준 |
|------|------|------|------|
| 0. 정리 | 쓰지 않는 추천 API·대상 코드 정리, 빈 상태 문구 수정, 디자인 상태를 하나의 JSON 모델로 통합 | S | 이름표 화면에 예전 Maker 문구가 없음. 디자인 JSON 하나로 미리보기·내보내기가 동작 |
| 1. 형상 엔진 | 불리언 합체, 양각/음각, 판 모양 확장, 구멍 옵션, Worker 계산 | L | 4-A 완료 기준 통과 |
| 2. 출력 검사 | 검사 항목·기준값, 위치 표시, 보정 제안, 견적 차단 규칙, 실물 출력 테스트 | M | 4-B 완료 기준 통과 |
| 3. 편집기 | 줄 1~3, 정렬·자간, 자동 맞춤, 2D 편집 미리보기, 프리셋 갤러리, 실행 취소, 모바일 | L | 다섯 프리셋 모두 3분 안에 완성 가능(내부 사용성 테스트 5명) |
| 4. 주문 연계 | 색 2종·3MF, 가격 미리보기, 디자인 JSON 전달, 관리자 재생성, 자동 저장·공유 | L | 이름표 주문이 관리자 화면에서 문구·색·수량과 함께 보이고, 같은 형상을 다시 내보낼 수 있음 |
| 5. 공개 준비 | 형상·폰트·화면 자동 테스트, 이용 지표, `/maker` 색인 허용과 SEO 등록, 안내 문구 | M | 6절 공개 체크리스트 전부 통과 |
| 6. 확장 | 단체 주문, 아이콘·이미지, 폰트 추가, AI 추천 | L | 단체 30명 목록이 한 번에 견적으로 넘어감 |

1~2단계가 끝나기 전에는 화면 기능(3단계)을 늘리지 않습니다. 형상이 불안정한 상태에서 편집 기능을 늘리면 출력 불량만 늘어납니다.

## 6. 공개 체크리스트

- [ ] 모든 프리셋에서 내보낸 파일이 단일 매니폴드다
- [ ] 출력 불가 디자인은 견적으로 넘어가지 않는다
- [ ] 공정별 실물 샘플을 출력해 글자 판독을 확인했다
- [ ] 미리보기 부피와 견적 부피가 1% 이내로 맞는다
- [ ] 견적·주문에 문구·폰트·색·수량이 남고, 관리자가 다시 만들 수 있다
- [ ] 모바일(375px 폭)에서 처음부터 견적 이동까지 막힘이 없다
- [ ] 첫 진입 후 3D 미리보기가 나오기까지 일반 LTE 기준 3초 이내다
- [ ] 폰트 라이선스(OFL) 고지가 있다
- [ ] 자동 테스트가 배포 전에 실행된다
- [ ] `/maker` 색인 허용, sitemap·`lib/content-dates.ts` 등록, 서버 렌더링 설명·FAQ가 있다

| 항목 | 결정 | 이유 |
|------|------|------|
| 불리언 | `manifold-3d` | 브라우저 WASM, 매니폴드 결과 보장, Apache-2.0 |
| 폰트 윤곽 | `opentype.js` 유지 | 이미 동작 확인. 한글 윤곽 정확 |
| 3MF | `fflate` 또는 `jszip`(이미 의존성에 있음)로 직접 작성 | 새 의존성 없이 색 정보 포함 가능 |
| 디자인 모델 | 버전 필드가 있는 JSON 1개 | 미리보기·내보내기·공유·주문 재생성이 같은 입력을 씀 |
| 연산 위치 | Web Worker | 입력 중 화면 멈춤 방지 |
| 기존 스케치 Maker | "로고 직접 그리기"로 유지, 이름표와 코드 분리 | 이름표 엔진 변경이 스케치 기능을 깨지 않게 함 |

## 8. 위험과 대응

| 위험 | 대응 |
|------|------|
| `manifold-3d` WASM 용량·초기화 시간 | `/maker`에서만 지연 로드. 초기화 전에는 기존 돌출 미리보기를 보여 줌 |
| 한글 폰트 용량 | 선택 시 내려받기, 서브셋, 입력 글자 기반 서브셋 검토 |
| 출력 기준값이 실제와 다름 | 공정별 실물 테스트 후 확정. 확정 전에는 경고만 하고 차단하지 않음 |
| 2색 출력 가능 여부 | 장비 보유 여부 확인 후 공개 범위 결정. 불가하면 음각 + 색 채움 후가공으로 대체 |
| 단체 주문 파일 수 | 파일 1개에 여러 이름표를 배치하는 방식도 함께 검토 |
