## 1. 현상

한 사용자가 **서로 다른 파일 2개 이상**을 견적·장바구니에 넣으면,  
각 파일을 **따로 견적했을 때 합**보다 **총액이 눈에 띄게 낮아짐**.

## 2. 재현·학습 실행 결과

### 2.1 캘리브레이션 (`npm run calibrate:quotes`)

- 대표 모델 FDM↔DLP/SLA 비율: 소형은 목표대, 중·대형은 DLP/SLA가 다소 높음 (기존과 유사).
- `calibrate-samples.json`에 Creality 실측(AMR VA/GA) 행을 **추가**해 두었음.

### 2.2 AMR 3MF 사이트 견적 vs 슬라이서

| 파일 | 사이트 해석 | 사이트 견적(FDM·VAT·최소 2만) | Creality 실측 |
|------|-------------|-------------------------------|---------------|
| VA zig | 79.75cm³ · 300×150×9mm · 표면 2178cm² | ≈ ₩52,200 · ≈98.9g | 6h23m · **94.48g** (서포트≈24g) |
| GA zig | **VA와 동일 메시로 해석됨** | 동일 ₩52,200 · 98.9g | 1h19m · **51.06g** |

- VA: **무게는 슬라이서와 유사**(약 +5%). 시간은 리포트 재실행으로 확인 권장.
- GA: 사이트 3MF가 VA와 **같은 기하**로 나와, 슬라이서(더 짧고 가벼움)와 **큰 괴리**. STEP/다른 내보내기·플레이트 설정 차이 가능성 → 별도 확인 과제.
- 슬라이서 공통: **인필 70%**, 플레이트 경계 경고 → 실제 출력·배치 비용은 우리 견적보다 불리할 수 있음.

### 2.3 다파일 배치 가격 (핵심)

동일 FDM + 동일 소재로 장바구니에 넣으면 `lib/quote-batch-price.ts`의  
`priceCartLinesByMaterialGroup`이 적용된다.

| 시나리오 | 단건 합 | 장바구니 | 비율 |
|----------|---------|----------|------|
| AMR VA+GA (인필 70%, 사이트 견적) | ₩104,400 | ₩97,200 | **0.93배** (−₩7,200 ≈ 셋업 1회분) |
| 둘 다 **최소금액대** (변동비 작음) | ₩44,000 | ₩22,000 | **0.50배** (−₩22,000) |
| 중간 변동비 | — | — | **≈0.81배** |
| 높은 변동비 | — | — | **≈0.91배** |

**결론:** “2개 이상이면 너무 싸다”의 **1차 원인은 단건 공식 오류가 아니라,  
같은 출력방식·소재 그룹에서 셋업비·장비 최소금액을 1회만 물리는 배치 정책**이다.  
특히 **최소금액에 걸리는 소형 다파일**에서 체감이 가장 큼(거의 반값).

## 3. 원인 정리

### A. 의도된 정책 (문서·FAQ에도 “최소금액 방식·소재당 1회”)

```
그룹 공급가 = max(셋업) + Σ(변동비 × 수량)
그룹 공급가 = max(그룹 공급가, 최소금액 1회)
```

- 장점: 같은 소재로 여러 부품을 한 번에 뽑을 때 현실에 가깝다.
- 단점: **파일이 달라도** 한 판에 못 넣거나(베드 초과·별도 잡),  
  잡이 사실상 2회인데도 최소/셋업이 1회만 잡혀 **과소 견적**.

### B. AMR처럼 큰 프레임

- 단건은 이미 최소금액 위 → 배치 시 **셋업 중복 제거(≈7천원)** 정도만 할인.  
  “반값”까지는 아니지만, 슬라이서상 **별도 잡·경계 초과**면 할인 자체가 과할 수 있음.

### C. (부수) 기하·시간 추정

- 얇은 프레임은 인필 15/70% 견적 차이가 거의 없음(쉘 지배).
- GA 3MF≡VA 해석이면 **파일별 단가도** 슬라이서와 어긋남 → 다파일 합산 왜곡 가중.

## 4. 수정 계획

### Phase 1 — 배치 정책 안전장치 ✅ 구현

1. **베드 적합 여부로 그룹 분리** (`lib/quote-batch-price.ts`)  
   - AABB가 베드에 안 들어가면 `solo:` 그룹.  
   - hybrid에서 같은 소재라도 XY 발자국 합 > 베드면적×0.9 이면 라인별 분리.

2. **최소금액 적용 방식** (`store_settings.cart_batch_min_price_mode`)  
   - 기본값 **`hybrid`**  
   - `once_per_material` / `once_per_quote_line` / `hybrid`  
   - 관리자: 설정 → 상점 기본 설정. 주문 서버도 동일 키 로드.

3. **다파일 UI 고지**  
   - 카트/체크아웃 `methodBundleHint` 문구 갱신 (ko/en).

4. **단위 테스트**  
   - `npm run test:batch-price` → `scripts/test-quote-batch-price.ts`

### Phase 2 — AMR·슬라이서 정렬 (학습 보강)

1. GA/VA **STEP vs 3MF** 메시가 정말 동일한지 확인. 다르면 파서/단위 이슈 수정.  
2. Creality 실측(인필 70%·서포트)을 `calibrate-samples.json`에 유지하고  
   `suggest-calibration` / P2S 시간·서포트 계수와 비교표 갱신.  
3. 서포트 비중이 큰 얇은 프레임에 대해 오버행→서포트 g 추정 점검.

### Phase 3 — 정책 상품화 (선택)

- “한 판 배치 할인”을 **명시적 옵션**으로: 기본은 라인별 최소,  
  고객이 “한 번에 출력” 체크 시에만 그룹 최소.  
- 또는 다파일일 때 최소금액을 `min × min(파일수, N)` 상한으로 완화.

## 5. 권장 착수 순서

```
1) 장바구니/주문에 현재 배치 절감액 표시 (투명화)
2) 베드 미수용 파일은 그룹 분리 (과소 견적 차단)
3) 관리자 설정: 최소금액 once_per_line | once_per_material | hybrid
4) AMR STEP 재해석 + 슬라이서 대비 시간 리포트 재실행
5) 테스트·스토어 안내 문구
```
